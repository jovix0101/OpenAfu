# 合成帧样本与逐字节解析

**全部是合成演示值**（统一人设：175 cm / 42 岁 / 男 / 78.40 kg / 阻抗 500、514 Ω / `k = 0.9788`），不含任何真实测量数据。造数据的原则见 [`../docs/07-privacy.md`](../docs/07-privacy.md)。

跑一遍：

```bash
python3 samples/decode.py
# 自检通过：6 帧校验和、体重位域、两路阻抗、用户信息、体成分模型均一致。
```

## 通用形状（所有帧恒 20 字节）

```
idx   0     1     2 ........................ 17    18     19
      AC    dev   载荷（16 字节）                 cmd    checksum
```

`checksum = sum(b[2..18]) & 0x1F`（只取低 5 位；主机写出去的帧用 `& 0xFF` 也能通过，因为低 5 位相同）。下面的样本都同时满足两种算法。

设备类型：通知帧 `0x29`，主机写帧 `0x27`。命令字在 `b[18]`，不是最后一字节。

---

## 1. `0xD5` 体重帧（锁定，78.40 kg）

```
ac 29 80 09 32 40 02 00 05 40 00 64 00 00 00 00 00 29 d5 a4
```

| 字节 | 值 | 含义 |
| --- | --- | --- |
| `b[0..1]` | `ac 29` | 帧头 + 设备类型 |
| `b[2..5]` | `80 09 32 40` | `core`（**大端**）= `0x80093240` |
| `b[6]` | `02` | `mode = 2`（带 support_funs 位图） |
| `b[7..10]` | `00 05 40 00` | support_funs 位图 |
| `b[11]` | `64` | battery = 100% |
| `b[17]` | `29` | alg_type = 41 → WLA41 |
| `b[18]` | `d5` | 命令字 |
| `b[19]` | `a4` | 校验和 `sum(b[2..18]) = 0xa4`，低 5 位 `0x04` |

`core` 位域：

```
weight_g     = core & 0x3FFFF      = 78400  → 78.40 kg
kg_division  = (core & 0x1C0000)>>18 = 2
lb_division  = (core & 0xE00000)>>21 = 0
dianji       = bit24 = 0           → 4 电极
state        = bit31 = 1           → 已锁定，可以存档
```

> 端序：这里按**大端**读。`ICStreamBuffer.ReadInt()` 在 `SetLittleEndian(true)` 下不做字节交换，非常容易按小端算错。

## 2. `0xD6` 阻抗帧（500 / 514 Ω）

```
ac 29 02 00 01 f4 02 02 01 80 09 32 40 00 00 00 00 29 d6 f6
```

载荷 `p = b[2..17]`：

| 位置 | 值 | 含义 |
| --- | --- | --- |
| `p[0]` = `b[2]` | `02` | ADC 个数 `n = 2` |
| `p[1]` = `b[3]` | `00` | 跳过 |
| `p[2..3]` | `01 f4` | adc1 = 500（大端） |
| `p[4..5]` | `02 02` | adc2 = 514（大端） |
| `p[6]` | `01` | `mode = 1`（必须） |
| `p[7..10]` | `80 09 32 40` | `core`（与体重帧同位域）= 78.40 kg / state 1 |
| `b[17]` | `29` | alg_type 41 |
| `b[18..19]` | `d6 f6` | 命令字 + 校验和 |

两路 ADC 都 `< 1500`，按 `ICWeightScale27Worker.java:487-500` 直接当 Ω：

```
Z1 = 500 Ω,  Z2 = 514 Ω,  Zavg = 507 Ω
FFM = k·H²/Zavg = 0.9788 × 175² / 507 = 59.12 kg
fat = 78.40 − 59.12 = 19.28 kg → 24.6%
water 37.4 kg / protein 18.4 kg / muscle 56.2 kg / skel 25.9 kg
BMR = 370 + 21.6×59.12 = 1647 kcal     BMI = 25.6
```

`decode.py` 里对 `Z = 0` 会拒绝算体脂 —— 这正是真实调试中「只报体重不报体脂」的那一类帧。

## 3. `0xD8` 历史帧（离线记录）

```
ac 29 01 68 f2 a1 c4 80 09 32 40 00 00 00 00 00 00 29 d8 bc
```

| 字节 | 值 | 含义 |
| --- | --- | --- |
| `b[2]` | `01` | kind = 1（普通记录；42 是另一种格式） |
| `b[3..6]` | `68 f2 a1 c4` | Unix 秒（大端）= 1760731588；真实设备上这个 RTC 可能明显错乱，超出合理年份要丢弃 |
| `b[7..10]` | `80 09 32 40` | `core` = 78.40 kg / state 1 |
| `b[11..16]` | `00 …` | adc / remainingHistoryCount 等（这里是零阻抗记录） |
| `b[18..19]` | `d8 bc` | 命令字 + 校验和 |

**收到必须回 `history-ack(216)`**，否则秤每 1.5 秒重发同一条。

## 4. 写：时间帧（`operate_type = 8`）

```
ac 27 08 82 97 ec 6a 20 00 00 00 00 00 00 00 00 00 00 df 76
```

| 字节 | 值 | 含义 |
| --- | --- | --- |
| `b[0..1]` | `ac 27` | 帧头 + `getDeviceType()` = `deviceSubType｜32` = `0x27` |
| `b[2]` | `08` | `operate_type = setTime` |
| `b[3..6]` | `82 97 ec 6a` | `time`（**小端** int32）= 1793890178 |
| `b[7]` | `20` | `utc_offset/900` = 32（东八区 28800 秒） |
| `b[8..17]` | `00 …` | 补零 |
| `b[18]` | `df` | `BuildConfig.VERSION_CODE` = 223 |
| `b[19]` | `76` | 校验和 |

**订阅 `FFB2` 之后必须写这一帧**，秤才会开始推数据。

## 5. 写：用户信息帧（`encode(1)`）

```
ac 27 82 97 ec 6a 20 00 01 af a0 1e 2a 01 a0 1e 01 00 d0 b7
```

| 字节 | 值 | 含义 |
| --- | --- | --- |
| `b[2..5]` | `82 97 ec 6a` | `time`（小端）—— **注意不是 operate_type** |
| `b[6]` | `20` | utc/900 |
| `b[7]` | `00` | unit = kg |
| `b[8]` | `01` | user_index |
| `b[9]` | `af` | height = 175 cm |
| `b[10..11]` | `a0 1e` | `weight×100`（小端 short）= 7840 |
| `b[12]` | `2a` | age = 42 |
| `b[13]` | `01` | sex = 男（女 = 2） |
| `b[14..15]` | `a0 1e` | `target_weight×100` = 7840 |
| `b[16]` | `01` | flags：**bit0 = `fun_open_imp`**（体脂测量总开关） |
| `b[17..18]` | `00 d0` | 保留 + 帧尾 |
| `b[19]` | `b7` | 校验和 |

`fun_open_imp = 0` 会让秤只报体重、`0xD6` 恒 `[0,0]`、秤屏也不显示体脂 —— 看起来像坏了。写回这一帧即可恢复，别重置设备。

## 6. 写：历史确认（`operate_type = 4`）

```
ac 27 04 d8 00 00 00 00 00 00 00 00 00 00 00 00 00 00 df bb
```

`b[2] = 04` (reply)，`b[3] = d8` (216 = 确认历史记录)。另外 `214` = 传感器开始、`215` = 传感器结束。

## 自己造一套合成帧

```python
def seal(body: list[int]) -> list[int]:
    assert len(body) == 19
    return body + [sum(body[2:]) & 0xFF]

# 例：体重帧，W = 78.40 kg、kgDiv = 2、state = 1
core = (1 << 31) | (2 << 18) | 78400
f = seal([0xAC, 0x29] + list(core.to_bytes(4, "big")) + [0x02, 0, 0x05, 0x40, 0, 0x64] + [0] * 5 + [0x29, 0xD5])
assert (sum(f[2:19]) & 0x1F) == (f[19] & 0x1F)
```

要点：`core` / `adc` / 历史 `time` 用**大端**；写出去的 `time` / `weight×100` 用**小端**；`b[18]` 才是命令字。
